# HH-bot: Автоматизация поиска вакансий и откликов на hh.ru

Автоматизированный комплекс для поиска работы на **HeadHunter (hh.ru)** с поддержкой умного автоответчика на вопросы работодателей и управлением через **Telegram-бота**.

---

## 🚀 Основные возможности

* **Умный поиск вакансий**:
  * Фильтрация вакансий по стеку (например, `QA тестировщик`), опыту, городу и исключениям (`Java`, `1C`, `Senior`).
  * Эмуляция реального пользователя с защитой от детекта автоматизации.
  * Паузы между действиями (6–12 сек.) и настраиваемый суточный лимит откликов.
* **Гарантия резюме и письма**:
  * Целевой выбор нужного резюме из аккаунта.
  * Обязательное прикрепление и проверка заполнения сопроводительного письма перед отправкой.
  * Защита от дубликатов (локальная SQLite база `hh_agent.db`).
* **Чат-ассистент (Chat Responder)**:
  * Проверяет отклики и чаты с работодателями (`https://hh.ru/applicant/negotiations`).
  * Распознает стандартные вопросы HR-ботов и отвечает по вашему профилю:
    * Зарплатные ожидания
    * Формат работы (удаленка, гибрид, офис)
    * Готовность к выходу
    * Уровень английского языка
    * Гражданство и локация
    * Готовность к тестовому заданию
  * При нестандартных вопросах или приглашениях на собеседование моментально присылает уведомление со ссылкой в Telegram.
* **Управление из Telegram**:
  * Интерактивная клавиатура прямо в мессенджере.
  * Кнопки: `🚀 Запустить HH Auto Agent`, `💬 Проверить чаты`, `📊 Статистика`, `⚙️ Статус`.
  * Автоматический отчет после каждого прогона со списком компаний и ссылками.

## 📂 Структура проекта

```text
├── agent.py                       # Движок поиска вакансий и отправки откликов
├── chat_responder.py              # Автоответчик на вопросы работодателей в чатах

├── requirements.txt               # Зависимости Python
├── .env.example                   # Шаблон переменных окружения
├── candidate_profile.example.json # Шаблон анкеты кандидата для автоответов
├── cover_letter.example.txt       # Шаблон сопроводительного письма
├── run_bot.bat                    # Быстрый запуск Telegram-сервиса
├── run_agent.bat                  # Разовый запуск поиска без Telegram
└── stop_bot.bat                   # Быстрая остановка всех процессов бота
```

## 🛠️ Установка и настройка

### 1. Клонирование репозитория
```bash
git clone https://github.com/perunov84-gif/HH-bot.git
cd HH-bot
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
python -m playwright install chromium
```

### 3. Настройка конфигурации
1. Скопируйте `.env.example` в `.env`:
   ```bash
   cp .env.example .env
   ```
   Заполните:
   * `TELEGRAM_BOT_TOKEN` — токен бота от [@BotFather](https://t.me/BotFather).
   * `TELEGRAM_CHAT_ID` — ваш цифровой ID от [@userinfobot](https://t.me/userinfobot).
   * `HH_RESUME_ID` — хэш резюме из адресной строки hh.ru (`https://hh.ru/resume/<хэш>`).
   * `HH_SEARCH_URL` — ссылка на ваш поиск со всеми фильтрами.

2. Скопируйте `candidate_profile.example.json` в `candidate_profile.json` и укажите свои данные (зарплата, формат, контакты).
3. Скопируйте `cover_letter.example.txt` в `cover_letter.txt` и вставьте свое сопроводительное письмо.

## 🚦 Запуск

### Шаг 1. Однократный вход на hh.ru
Чтобы бот не запрашивал СМС-коды при каждом запуске:
```bash
python login.py
```
В открывшемся браузере войдите в профиль hh.ru, затем нажмите `Enter` в консоли. Сессия сохранится в `user_data`.

### Шаг 2. Запуск сервиса
Дважды кликните по `run_bot.bat` (или запустите `python telegram_service.py`).
В Telegram откройте вашего бота и нажимайте кнопки меню!

## 🔒 Безопасность

Файлы `.env`, сессия браузера `user_data/`, база данных `hh_agent.db`, персональный профиль `candidate_profile.json` и файл `cover_letter.txt` включены в `.gitignore` и **никогда не попадают в репозиторий**.
